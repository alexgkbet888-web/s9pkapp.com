S9 account already exists register error

This guide covers the moment when a user tries to register but the app says the account already exists.

Quick checklist

  1. Switch from Register to Login if the number is already used.
  2. Use forgot password if the original password is lost.
  3. Check whether the number belongs to the current user.
  4. Avoid duplicate accounts that can create verification risk.
